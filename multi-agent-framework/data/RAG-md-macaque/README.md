# data/RAG-md-macaque/

This directory should contain the Markdown-converted full text of the 3 macaque papers
listed below (the same corpus used in [`../../rag-evaluation`](../../rag-evaluation)).
Full text is not redistributed in this repository due to publisher copyright — obtain
each paper yourself (e.g. via your institution's journal access) and convert it to
Markdown using a PDF-to-Markdown tool of your choice, then place the result here using
the naming pattern `<First author> et al - <year> - <short title>.md`.

1. Gou, L. et al. Single-neuron projectomes of macaque prefrontal cortex reveal refined axon targeting and arborization. *Cell* 188, 3806–3822.e24 (2025). https://doi.org/10.1016/j.cell.2025.06.005
2. Chen, A., Sun, Y. et al. Single-cell spatial transcriptome reveals cell-type organization in the macaque cortex. *Cell* 186, 3726–3743.e24 (2023). https://doi.org/10.1016/j.cell.2023.06.009
3. Single-cell spatial transcriptome atlas and whole-brain connectivity of the macaque claustrum. *Cell* (2025). https://doi.org/10.1016/j.cell.2025.02.037

See [`../../rag-evaluation/data/SOURCE_PAPERS.md`](../../rag-evaluation/data/SOURCE_PAPERS.md)
for the full corpus overview (mouse + macaque).
